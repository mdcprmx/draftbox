- Чо такое root юзер?
    -  UID 0, отключён по умолчанию, неограниченные права - может изменять ЛЮБОЙ файл и менять права/владение файлов и папок без ограничений со стороны системы,

- Системный юзер эт кто?
    - Оперируют в бэкграунде, в основном юзаются чтоб раннить системные сервисы и приложухи 
    - Создаются автоматический, во время установки ОС

    - Они имеют UID, GID, home dir, default shell, password.
    - Имеют разные роли

    - Network Time Protocol, протокол синхронизации времени в пределах милисекунд по UTC (Coordinated Universal Time) между множеством компьютеров

### Блок 3 - Docker

- Что такое докер?
    - Платформа для разработки, доставки, и запуска контейнерных приложений. Позволяет упаковывать приложения со всеми зависимостями в контейнеры - которые потом можно запустить на различных системах без доп настройки
    - Основные концепты докера:
        - Контейнеры - изолированные среды в которых запускаются приложения. Используют ядро-хост системы и разделяют ресурсы с другими контейнерами; это делает их более эффективными по сравнению с ВМ-ками.
    - Докер не имеет "ядра" типа-жа ЦПУ, но взаимодействует с кернелом хост-машины. 
- Разница между докером и Виртуальной машиной
    - Докеры работают на уровне приложений, запаковывая приложение в контейнер. Эти контейнеры имеют общий с хост системой kernel, что делает их лёгковесными для запуска.
    - В то время как ВМ-ки эмулируют компьютер полностью, включая Операционную Систему и железо. И требуют ощутимое количество ресурсов - RAM, мощности CPU, и всё вот это вот~
- как узнать версию docker?
    - docker info
    - docker version
    - да, тут два верных ответа
- Что такое контейнер?
    - активный образ, который можно запустить/остановить/перезагрузить
    - в него также можно зайти и работать в нём почти как в ВМ
    - через него можно запускать приложения и/или поднимать веб серверы
- Что такое образ?
    - незменяемый файл, из которого разворачивается контейнер
    - его нельзя запустить
- Что такое dockerhub?
    - централизованная платформа для шэринга, хранения, и менеджмента контейнер имэйджов
    - это контейнер регистри, регистр контейнеров
- Что такое dockerfile?
    - текстовый документ, с директивами. Чертёж для создания контейнера
    - написанны на DSL (Domain Specific Language) языке
- Что такое docker registry?
    - это место для хранения и распространения образов docker.
- Разница между командой **docker create** и **docker run**?
    - В том что **create** только создаёт, а **run** создаёт и сразу же запускает контейнер.
- Как создать образ после изменений в контейнере?
    - docker commit
